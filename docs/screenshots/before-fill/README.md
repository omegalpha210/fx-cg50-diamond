# Frozen own renderer baseline

These PNGs were generated using DIAMOND's baseline `1f26635` drawing functions.
The piece-readability pair uses the same ten-piece-per-player fixture driver and
`dg_screen_position()` crop metadata as the current renderer. No reference app,
article, board photograph or private image is included.

The eight full frames and `piece-samples.csv` supply the public-safe before/after
comparisons. They remain frozen when current images are regenerated. Original
PNG pixels are retained; comparison sheets enlarge crops by integer nearest
neighbor only. See [UI_BETA_AUDIT.md](../../UI_BETA_AUDIT.md).
